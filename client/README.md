# Agentica Frontend 💻

The interactive interface for the Agentica Squad. Built with **Next.js 15**, it offers a futuristic, glassmorphic UI for seamless AI collaboration.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React

## 🔑 Environment Variables
Create a `.env.local` file in this directory:
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## 🚀 Running Locally
```bash
# 1. Install Deps
npm install

# 2. Run Dev Server
npm run dev
```
Client runs at `http://localhost:3000`.

## 📦 Features
- **Sidebar**: Global navigation to Chat, Projects, Imagine, and Profile.
- **Chat Interface**: Real-time streaming chat with voice controls.
- **Imagine Page**: AI Image generation.
- **Profile**: User stats and settings.
- **Projects**: Workspace management.
